# Code of conduct

Be kind, be direct, assume good faith. Criticise code, not people. No harassment, discrimination or personal attacks in issues, pull requests, discussions or anywhere else this project meets.

Maintainers may edit, remove or lock content that breaks this, and may block repeat offenders. To report a problem, message the maintainer directly (https://github.com/vivek-brownie) or open a private security advisory on the repository and mark it "conduct".
